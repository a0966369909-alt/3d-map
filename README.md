# 木光三義｜木雕文化探索館

介紹苗栗三義木雕工藝與山城探索的繁體中文響應式網站，支援電腦與手機瀏覽。

## 互動功能

- 體驗會員表單：暱稱與電子郵件存在目前瀏覽器的 `localStorage`。
- 角色聊天：可選擇職人阿木、山城旅人或選物店長，進行網站內的示範對話。
- 商品展示與購物車：可加入、移除商品並計算總額，購物車會保存在目前瀏覽器。
- 手機版導覽與聊天面板。

## 本機預覽

直接以瀏覽器開啟 `index.html`。網站使用 Google Fonts 與 Unsplash 圖片，查看時需連上網路。

## 部署到 Vercel

1. 將此資料夾內容推送到 GitHub 儲存庫。
2. 在 Vercel 選擇 **Add New Project** 並匯入該儲存庫。
3. 這是純靜態網站，不需要建置指令；輸出目錄使用專案根目錄。
4. 按下 Deploy，即可取得網站網址。

## 正式上線前

目前會員、角色對話與購物車都是前端體驗版。尚未有安全的帳號驗證、多人聊天、商品資料庫、庫存、訂單、金流或配送串接；正式營運需接上後端與付款服務。範例商品與外部照片僅作展示，正式發布前請換成實際商品資料及取得授權的照片。景點資訊以場館公告為準。

## 動態效果

包含首屏文字淡入、捲動進場、作品與商品卡片互動、插畫微動、聊天面板彈出等效果；訪客若設定減少動態，網站會自動降低動畫。

- 可互動的 Three.js 3D 木雕場景：拖曳旋轉、滾輪縮放、點選故事光點；需連網載入 Three.js CDN。
